# 05. Web Application Security

Identify and exploit SQL Injection vulnerabilities.

## 🛠️ Tools Used
- DVWA
- WebGoat
- Burp Suite
- OWASP ZAP
- SQLMap

## 🔎 Methodology
1. Identified input fields.
2. Tested manual SQL injection.
3. Automated exploitation.

- SQL injection vulnerability confirmed.
- Data extraction possible.

## 🛡️ Mitigation

- Prepared statements
- WAF implementation
